# Replit prompt — Detent Agentic Website Assistant

**Update: the app now starts without a package manager, and tells you why if it
cannot.** Fixes "the app is not running".

---

## The zero-credit route

If your Replit project is a git checkout, you do not need the Agent or the zip.
In the **Shell** tab:

```
git pull origin claude/enterprise-agentic-assistant-vybrfm
node tools/doctor.mjs
node tools/serve.mjs
```

`doctor` prints a preflight table and exits non-zero if the app genuinely cannot
start. **Zero Agent requests.**

If it is not a git checkout, unzip over the project, then run the same two
commands.

## Why it was not running

Two causes, both packaging faults on our side, and neither visible from inside
the process — because in both the process never started.

1. **`.replit` ran `pnpm serve`.** pnpm is not guaranteed to be on PATH in a
   Replit container; it usually needs corepack enabling. A run command that is
   not found produces no output at all. Node is always present, so `run` now
   invokes **node** directly. No package manager is on the start path.
2. **The TypeScript fallback assumed a flag that may not exist.** With tsx
   absent, it used `--experimental-transform-types`, which needs Node 22.6+.
   Older Node rejects an unknown flag with "bad option" and exits on the first
   line. The runner now **probes** each strategy with a throwaway process before
   trusting it, and if none works it says so, naming your Node version and both
   fixes.

Plus `tools/doctor.mjs`: a preflight that names the cause instead of leaving you
with "not running". `.replit` runs it before the server.

## What a healthy preflight looks like

```
ok    Node                          v22.x
ok    Node has built-in TypeScript  yes (22.6+)
--    tsx installed                 no (optional)
--    node_modules present          optional — the app runs without it
ok    Can run TypeScript            via Node built-in transform
ok    Status page present           /
ok    Bind address                  0.0.0.0:8787
```

Rows marked `--` are optional and are **not** problems: the product runs with no
dependencies at all. Only `FAIL` rows stop it.

## How to not burn credits

Replit charges per **Agent** request; the Shell is free. The cost driver is how
often the Agent re-reads your code and retries, and the expensive mistake is
letting it treat a finished repository as one to build.

1. **Do this in the Shell.** Zero requests.
2. **If you use the Agent, give it the exact commands.** They are below.
3. **Tell it what not to touch**, or it will refactor `packages/core` and you pay
   twice — once to do it, once to undo it.
4. **Never let it change a test to make the suite pass.** A green run bought that
   way costs more than it saves.
5. **Stop at green.**

Budget: **one Agent request.** Past three, go back to the Shell.

| Task | Command | Expected |
|---|---|---|
| Preflight | `node tools/doctor.mjs` | `Ready.` |
| Start | `node tools/serve.mjs` | `listening on 0.0.0.0:8787` |
| Tests | `node tools/test.mjs` | `387 passed` |
| Page | `curl -s -o /dev/null -w '%{http_code}' localhost:8787/` | `200` |
| Health | `curl -s localhost:8787/health` | `{"status":"ok",...}` |

Every command is plain `node`. None needs pnpm, npm or `node_modules`.

```
Do exactly this, in order, and STOP at the first step that does not match.

1. node tools/doctor.mjs
   This prints a preflight table. Rows marked -- are OPTIONAL and are not

3. Open the preview.

   If it is blank or shows JSON, STOP and tell me what you see.

4. node tools/test.mjs
   Expect: 387 passed. If any test fails, paste the output and STOP.
   Do NOT edit, skip or delete a test to make the suite pass.

Report the preflight table, the boot line, and what the preview shows. STOP.
```

## If it still will not start

Run the preflight and send me the whole table plus any error:

```
node tools/doctor.mjs
node tools/serve.mjs
```

That output names the cause. Without it I am guessing, and guessing costs you
credits.

## Do not

- Do not run `pnpm install --no-optional`. It breaks esbuild's platform binary,
  which tsx needs, and turns a working install into a broken one.
- Do not change a test to make the suite pass.
- Do not set `HOST` to anything but `0.0.0.0` in Replit.
