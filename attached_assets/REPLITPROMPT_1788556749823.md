## How to apply an update — zero credits

**Do not use `git pull`.** Your Replit workspace is not a git checkout, and its
root holds what this repo keeps in a subdirectory, so a pull would nest the files
one level down and break the layout. The zip is the delivery mechanism.

1. Drag `detent-agentic-website-assistant.zip` into the Replit file pane.
2. In the **Shell**:

```
pkill -f 'packages/server/src/main.ts' ; pkill -f tools/serve.mjs
unzip -o detent-agentic-website-assistant.zip
cp -r detent-agentic-website-assistant/. . && rm -rf detent-agentic-website-assistant
node tools/doctor.mjs
node tools/serve.mjs
```

The `pkill` first line matters: a running server holds port 8787, and a new one
cannot start while it does. **Zero Agent requests.**

## What was wrong, and what changed

The app would not start because a process from an earlier run still held port
8787. Node's response to that is an unhandled `EADDRINUSE` error event — a stack
trace and an instant exit — which Replit reports only as "the app is not
running", naming no cause.

That single stale process caused both symptoms. It was a build from before the
bind fix, listening on loopback only: reachable inside the container, invisible
to the preview proxy. That was "running, but the preview isn't ready". Once the
fixed build tried to start, the same process blocked it.

- **The preflight now tests the port** before the server does, and says whether
  the occupant answers `/health` (this app, already running) or answers nothing
  (a stale process). It prints the remedy, not the symptom.
- **The server explains itself.** `EADDRINUSE` and `EACCES` print what happened
  and how to clear it, then exit 1. No stack trace.

## How to not burn credits

Replit charges per **Agent** request; the Shell is free. The cost driver is how
often the Agent re-reads your code and retries.

1. **Apply updates in the Shell.** Zero requests.
2. **If you use the Agent, give it the exact commands.** They are below.
3. **Tell it what not to touch**, or it will refactor `packages/core` and you pay
   twice — once to do it, once to undo it.
4. **Never let it change a test to make the suite pass.**
5. **Stop at green.**

Budget: **one Agent request, and usually none.**

| Task | Command | Expected |
|---|---|---|
| Free a stuck port | `pkill -f 'packages/server/src/main.ts'` | no output |
| Preflight | `node tools/doctor.mjs` | `Ready.` |
| Start | `node tools/serve.mjs` | `listening on 0.0.0.0:8787` |
| Tests | `node tools/test.mjs` | `387 passed` |
| Page | `curl -s -o /dev/null -w '%{http_code}' localhost:8787/` | `200` |

Every command is plain `node`. None needs pnpm, npm or `node_modules`.
