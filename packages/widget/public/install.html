Content Security Policy


Add these three directives. Nothing else is needed.





Consent



  The widget reads your consent management platform's signal; it does not set
  its own. IAB TCF, OneTrust, Cookiebot and a dataLayer flag are
  detected automatically. To state the position explicitly, add
  data-consent-personalisation="granted" or "denied".




  Where no signal can be read, the assistant runs in non-resolving mode: it will
  not match the visitor against your CRM. It still answers, qualifies and books.
  Refusing consent costs the visitor nothing, which is the point.




Accessibility


    
  
  • The panel is keyboard operable throughout, has a visible close control, and returns focus to the launcher when it closes.
    • 
  
  • Escape closes it from inside the panel as well as from the host page.
    • 
  
  • On a phone the panel is a full-screen sheet and the composer stays above the on-screen keyboard.
    • 
  
  • The AI disclosure is on the launcher before anyone clicks, and on the first screen of every conversation. It is not disableable.
